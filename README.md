# toothless-assets

Severity badge images referenced by Toothless (Security Checker) PR review comments on
GitHub Enterprise Cloud (naver.ghe.com).

GHEC proxies every comment image through `camo.naver.ghe.com`, which can only fetch anonymously
reachable public URLs. Naver-internal hosts are not reachable from there, so these badges are
published here and referenced via `raw.githubusercontent.com/naver-security/assets/main/img/<name>.svg`.

Contents are limited to static text badges (e.g. "Warning | High") — no screenshots, recordings,
or internal URLs are published in this repository.
